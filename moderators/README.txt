MPSC Cultural Club - Moderators Image Folder
===========================================

Place your Moderator and 3 Co-Moderators profile photos in this folder with the following filenames:

1. 1.jpg (or 1.png) -> Main Moderator Photo
2. 2.jpg (or 2.png) -> Co-Moderator 1 Photo
3. 3.jpg (or 3.png) -> Co-Moderator 2 Photo
4. 4.jpg (or 4.png) -> Co-Moderator 3 Photo

Supported image formats: .jpg, .png, .jpeg, .webp

Note: If an image file is not found, it automatically falls back to logo.png until you upload your image.
